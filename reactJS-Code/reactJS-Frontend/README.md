## React  Files upload  with Progress Bar

We’re gonna create a React  Files upload application in that user can:

- see the upload process (percentage) of each file with progress bars
- view all uploaded files
- download link to file when clicking on the file name

  ![image](https://github.com/user-attachments/assets/4d849836-2fb9-427f-a66f-407aea2d8201)



### Set port
.env
```
PORT=8081
```

## Project setup

In the project directory, you can run:

```
npm install
# or
yarn install
```

or

### Compiles and hot-reloads for development

```
npm start
# or
yarn start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page will reload if you make edits.
